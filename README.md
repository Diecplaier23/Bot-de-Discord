# 🤖 Bot de Discord

Bot de Discord creado para facilitar la gestión y organización de una comunidad/campaña, ofreciendo diferentes comandos de utilidad para que los jugadores tengan información y enlaces importantes siempre a mano.

## 📌 Funciones

El bot cuenta con varios comandos pensados para facilitar el acceso a información útil dentro del servidor.

### `/miembros`

Permite consultar los miembros que forman parte de la campaña.

Para cada miembro se muestra:

* 👤 Nombre del usuario
* 🎭 Nombre de su personaje
* 🏷️ Rango interno dentro del mundo de la campaña

Esto permite consultar rápidamente quién participa en la campaña y qué personaje representa cada jugador.

### `/info`

Proporciona información y enlaces útiles relacionados con la campaña y el servidor, evitando tener que buscar manualmente estos recursos cada vez que se necesitan.

## 🛠️ Objetivo

El objetivo principal del bot es centralizar diferentes herramientas e información de utilidad dentro de Discord, haciendo que los jugadores puedan acceder a ellas mediante comandos sencillos.

El proyecto puede seguir ampliándose con nuevos comandos y funcionalidades según las necesidades de la comunidad.
